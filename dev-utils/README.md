# Дерево технологий

Откройте `tech-tree.html` в обычном браузере — интернет и сервер не нужны.

- Все 94 технологии текущего прототипа, от земледелия до технологии будущего; 151 обязательная связь.
- Поиск по русскому названию и строковому `Type`; Enter и стрелки перебирают результаты.
- Нажатие карточки подсвечивает всех предков и потомков. Справа — непосредственные требования, следующие исследования, удалённые требования, стоимость и позиция.
- Золотые карточки — тринадцать новых технологий; золотая левая граница — изменённые непосредственные требования. Пунктир — добавленная связь. Перемещения указаны в деталях.
- Масштаб и кнопка «Всё дерево» позволяют переключаться между обзором и чтением. Полотно прокручивается в обе стороны.

Обновление после изменения SQL:

```sh
python3 dev-utils/tech_tree.py
```

Генератор использует только стандартную библиотеку Python 3. Он берёт порядок SQL из `tools/build.py` и выполняет **только записи в `Technologies`, `Technology_PrereqTechs` и вспомогательную таблицу `Refined_VictoryTechs`**, включая SELECT-подзапросы. Остальные игровые изменения не нужны для графа и не исполняются. Названия новых технологий и их подсказки читаются из файлов `mod/Text/*.xml`. HTML автономный, с данными внутри; `tech-tree.template.html` — его редактируемый шаблон.

Для собственной **чистой** базы BNW:

```sh
python3 dev-utils/tech_tree.py --database /path/to/Civ5DebugDatabase.db
```

База открывается только для чтения и копируется в память. Не передавайте базу с уже включённым модом: повторный запуск миграций сдвинет координаты повторно. Генератор отклоняет базы с числом технологий, отличным от 81, и с `TECH_REFINED_*`.

## Происхождение данных и границы проверки

`data/bnw-tech-tree.json` — компактная фактическая проекция таблиц из [публичного снимка BNW в civvapi](https://github.com/Eyefyre/civvapi/blob/master/Civ5DebugDatabase.db), 81 технология / 135 связей. Русские названия — из [русского набора civvapi](https://github.com/Eyefyre/civvapi/blob/master/v1/ru/tech/tech.json), только именительный падеж. Сокращённые и устаревшие названия части карточек развёрнуты в `tech_tree.py` по терминологии проекта; `Type` сохранены. Длинные тексты Civilopedia, цитаты и игровые изображения не включены. Источник не является базой установленной у нас игры. В JSON сохранены URL источников, в HTML — SHA-256 текущих SQL для воспроизводимости.

Проверено 28 октября 2026: снимок и полная исходная база дают одинаковые итоговые узлы и связи; все связи ссылаются на существующие технологии, все узлы достижимы от земледелия, циклов и совпадений GridX/GridY нет. Проверены поиск и выбор ветки в браузере.

Это схема зависимостей и стоимостей до модификаторов, а не полный перечень зданий, юнитов, ресурсов и эврик. Форма соединительных линий схематическая: она не воспроизводит адаптеры штатного TechTree и не подтверждает корректность интерфейса в игре. Новые технологии и требования берутся из кода прототипа; стартовый баланс не становится проверенным игровым балансом.

## Расчёт сроков научной победы

`python3 dev-utils/victory_timing.py` сравнивает текущую победу v7 и три предложенных маршрута на фиксированной базе: 7 городов, 800/1000/1200 науки империи за ход и три уровня промышленности. Все города могут строить и участвовать в обучении. Комплектация, параметры и полные расписания выведены в JSON. `--cities 6` и `--cities 8` проверяют границы пользовательского ориентира; `--normalized` сохранён как синоним обычного запуска.

Это версия 2 расчётной модели после исправления городского штрафа науки (учитывает первый город) и отказа от прежних четырёх городов. Цены путей не перенастраивались. Старые таблицы имеют статус архива; использовать их для баланса нельзя. Предпосылки, границы и сверка — в [проекте путей победы](../docs/victory-paths.md). Модель не реализует новые технологии в игре и не симулирует весь движок.

Проверка формулы и расчётных сценариев: `python3 tests/victory_timing.py`.

Проверка предложения верфи +50%: `python3 dev-utils/victory_timing.py --yard-bonus 50 --require-yard`. Последний флаг требует фактического выпуска хотя бы одной детали в городе с уже построенной верфью. Без него маршрут вправе пропустить верфь; один лишь разрешённый заказ здания не доказывает применение бонуса. По умолчанию сохраняется предварительный бонус +20%.

## Общая схема обсуждения

`docs/images/science-victory-overview.png` — снимок трёх финалов, выбранных решений и открытых вопросов. Исходник — `dev-utils/victory-overview.swift`. На macOS обновляется без внешних библиотек:

```sh
swift -module-cache-path /tmp/civ5-diagram-module-cache dev-utils/victory-overview.swift
```

Текст и расположение редактируются в исходнике; генератор проверяет высоту текстовых блоков. После обновления нужно открыть PNG и проверить читаемость, отсутствие обрезанных строк и соответствие актуальным решениям. Это документация, в пакет мода изображение и генератор не входят.
